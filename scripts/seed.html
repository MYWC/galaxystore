🚀 درون‌ریزی محصولات

همه محصولات از فایل‌های js/data/products/*.js خوانده و به جدول products در Supabase فرستاده می‌شوند. محصولات تکراری به‌روزرسانی می‌شوند (upsert).

⚠️ قبل از شروع، این SQL رو توی Supabase اجرا کن تا اجازه‌ی insert بده:

CREATE POLICY "products_temp_insert" ON public.products FOR INSERT WITH CHECK (true);
CREATE POLICY "products_temp_update" ON public.products FOR UPDATE USING (true);

بعد از اتمام seed، حتماً این‌ها رو حذف کن:

DROP POLICY IF EXISTS "products_temp_insert" ON public.products;
DROP POLICY IF EXISTS "products_temp_update" ON public.products;
